# Planning and Pre-Change Approval Rule

1. **Detailed Plan First**:
   - Before editing, creating, or deleting code files, create or update `implementation_plan.md`.
   - Outline all affected files, rationale, and verification steps in detail.

2. **Strict User Approval Requirement**:
   - Stop and request explicit user confirmation before executing any code changes.
   - Do NOT run modifying file operations without prior approval.
